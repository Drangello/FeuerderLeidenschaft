# Spanisches Feuer der Leidenschaft 🔥

A 2D browser game built with object-oriented JavaScript.

The project focuses on structuring game logic with reusable classes and separating responsibilities for characters, enemies, levels, controls and interactive game elements.

## Features

* Object-oriented game architecture
* Player movement and controls
* Enemies and boss logic
* Multiple game objects and interactions
* Status bars and game states
* Level-based structure

## Tech Stack

* JavaScript
* HTML
* CSS
* Object-Oriented Programming
* Git

## What I learned

This project helped me understand how larger JavaScript applications can be structured with classes and reusable components instead of keeping all logic in one place.

It was also one of the projects that pushed me further into software development and made me want to understand more about application architecture and clean code.
